# Трекер съёмок

PWA для учёта съёмок, обработки, денег и личных дел: таблица и задачи, синхронизация через Google Drive, Google Календарь, выгрузка в ODS. Спецификация — [SPEC.md](SPEC.md).

## Запуск

```
npm install
npm run dev        # http://localhost:5173
npm test           # все тесты (vitest)
npm run build      # сборка в dist/
```

С телефона в той же Wi-Fi сети: `npm run dev -- --host`, открыть адрес `http://<IP-компьютера>:5173`. Синхронизация работает и с такого адреса, но офлайн-режим и «установить как приложение» требуют https — для телефона удобнее хостинг (см. ниже).

## Первый запуск

1. **Настройки → Импорт .ods** — выбрать старый файл. Мастер покажет найденные цвета строк: сопоставить каждый цвет с типом (основная / совместная / личное). Дальше — таблица проверки: подсвеченные строки парсер распознал неуверенно; кнопка «Всё раньше <даты> → деньги получены, закрыто» закрывает старые записи, где в файле не было пометки об оплате. Сверка месяцев с итогом SUM каждого листа — вверху.
2. **Настройки → Google Drive через Apps Script** — скопировать готовый код скрипта, вставить его на script.google.com, развернуть как веб-приложение (доступ «Все») и вставить ссылку `…/exec` в трекер. Инструкция пошагово — в самих настройках и в [src/sync/README.md](src/sync/README.md). Google Cloud Console и OAuth Client ID не нужны. На телефоне — вставить «ссылку для других устройств» с компьютера.
3. **Настройки → Календарь** — включить, если нужен календарь «Съёмки». Суммы в события по умолчанию не пишутся.

## Хостинг

Сборка статическая (`dist/`), подходит GitHub Pages или Cloudflare Pages. Настраивать в Google для адреса хостинга ничего не нужно. На телефоне открыть адрес и «Добавить на главный экран» — приложение работает офлайн.

## Устройство

| Папка | Что внутри |
|:---|:---|
| `src/model` | Типы данных и общие расчёты (итоги месяца, статус оплаты) |
| `src/store` | Локальное хранилище в IndexedDB |
| `src/ods` | Чтение .ods и импорт старого трекера, парсер быстрого ввода |
| `src/export` | Выгрузка в .ods, JSON-бэкап |
| `src/sync` | Синхронизация с Drive через Google Apps Script (`Трекер/tracker.json`), текст скрипта, слияние |
| `src/calendar` | Синхронизация с Google Календарём |
| `src/ui` | Экраны: таблица, задачи, календарь, деньги, итоги, настройки |

Файлы `*.ods` в корне в git не попадают (`.gitignore`). Чтобы прогнать тесты импорта на своём трекере: `TRACKER_ODS=путь/к/файлу.ods npm test`.
