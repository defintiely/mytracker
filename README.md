# Трекер работы

PWA для учёта работы фрилансера или небольшого бизнеса любой сферы: задачи, работа без даты, деньги (у клиента, у посредника, получено) и личные дела. Таблица и канбан, синхронизация через Google Drive, Google Календарь, выгрузка в ODS. Спецификация — [SPEC.md](SPEC.md).

## Запуск

```
npm install
npm run dev        # http://localhost:5173
npm test           # все тесты (vitest)
npm run build      # сборка в dist/
```

С телефона в той же Wi-Fi сети: `npm run dev -- --host`, открыть адрес `http://<IP-компьютера>:5173`. Синхронизация работает и с такого адреса, но офлайн-режим и «установить как приложение» требуют https — для телефона удобнее хостинг (см. ниже).

## Первый запуск

1. **Настройки → Типы задач и Категории** — по умолчанию есть три типа («Основная работа», «Совместная работа», «Личное») и короткий список категорий. Все типы равноправны: любой можно переименовать, перекрасить, переключить «с деньгами» и удалить (кроме последнего). Там же — «тип по умолчанию» и «тип для дел без денег».
2. **Настройки → Импорт .ods** (если есть старая таблица) — выбрать файл. Мастер спросит, какой тип ставить строкам с суммой и строкам без суммы, и покажет найденные цвета строк — цвет можно сопоставить с любым типом или с пометкой «важно». Дальше — таблица проверки: подсвеченные строки парсер распознал неуверенно; кнопка «Всё раньше <даты> → деньги получены, закрыто» закрывает старые записи, где в файле не было пометки об оплате. Сверка месяцев с итогом SUM каждого листа — вверху.
3. **Настройки → Google Drive через Apps Script** — скопировать готовый код скрипта, вставить его на script.google.com, развернуть как веб-приложение (доступ «Все») и вставить ссылку `…/exec` в трекер. Инструкция пошагово — в самих настройках и в [src/sync/README.md](src/sync/README.md). Google Cloud Console и OAuth Client ID не нужны. На телефоне — вставить «ссылку для других устройств» с компьютера.
4. **Настройки → Календарь** — включить, если нужен отдельный календарь (по умолчанию «Трекер»). Суммы в события по умолчанию не пишутся.

## Хостинг

Сборка статическая (`dist/`), подходит GitHub Pages или Cloudflare Pages. Настраивать в Google для адреса хостинга ничего не нужно. На телефоне открыть адрес и «Добавить на главный экран» — приложение работает офлайн.

## Устройство

| Папка | Что внутри |
|:---|:---|
| `src/model` | Типы данных и общие расчёты (итоги месяца, статус оплаты, типы задач) |
| `src/store` | Локальное хранилище в IndexedDB |
| `src/ods` | Чтение .ods и импорт старой таблицы, парсер быстрого ввода |
| `src/export` | Выгрузка в .ods, JSON-бэкап |
| `src/sync` | Синхронизация с Drive через Google Apps Script (`Трекер/tracker.json`), текст скрипта, слияние |
| `src/calendar` | Синхронизация с Google Календарём |
| `src/ui` | Экраны: таблица, задачи, календарь, деньги, итоги, настройки |

Файлы `*.ods` в корне в git не попадают (`.gitignore`). Чтобы прогнать тесты импорта на своей таблице: `TRACKER_ODS=путь/к/файлу.ods npm test`.
